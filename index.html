Quick answer: how to generate a password

To generate a password, choose a length (16 or more is a good default), pick which characters to include, and click Generate password. The tool builds a random password in your browser using your device's secure random number generator. Copy it, paste it into the password field, and keep it in a password manager.

Introduction

This password generator creates strong, unpredictable passwords in one click. It's a random password generator that lets you set the length, choose letters, numbers and symbols, and skip look-alike characters like O and 0. Pick your settings and the tool fills the box with a fresh password straight away.

Weak, reused passwords are still the easiest way into most accounts, and people are bad at inventing random ones. Let the computer do it. Nothing is sent to a server, nothing is saved, and there's no account to create.

Why use this free random password generator

Here's what's actually true about this tool:

  • Secure randomness. Characters are picked with crypto.getRandomValues, the browser's cryptographic random source, not Math.random.
  • No modulo bias. The code throws away out-of-range random values, so every character in your chosen set is equally likely.
  • Your rules, your length. Any length from 4 to 128, four character types and an option to skip look-alike characters.
  • Batch mode. Generate 1, 5, 10 or 20 passwords at once, useful when you're setting up several accounts.
  • Strength estimate. A live bar shows an entropy estimate in bits, based on your length and character set.
  • Private by design. The page makes no network requests while you generate, and it doesn't store passwords in cookies or local storage.
  • No signup, no ads inside the tool. It works the moment the page loads.

How to generate a password: step-by-step guide

Step 1: Choose a length

Drag the slider or type a number. Length does most of the work: each added character multiplies the number of possible passwords. Sixteen is a sensible everyday default. Go to 20 or more for email, banking and your password manager's master password.

Step 2: Choose characters

Leave all four types ticked unless a site forbids something. If a site rejects symbols, untick Symbols and add a few characters of length. Tick Easy to read if you'll ever read the password aloud or type it from a screen. If a site demands lowercase-only text, untick the other types here rather than converting the result with a case converter, which would weaken it.

Step 3: Generate and check strength

Click Generate password for a new result. The bar below the box rates it Weak, Fair, Strong or Very strong. The rating comes from entropy, a measure of how many guesses an attacker would need on average. Aim for Strong or better, and Very strong for important accounts.

Step 4: Copy it and store it safely

Click Copy and paste the password straight into the sign-up or change-password form. Then save it in a password manager. Don't keep it in a note, a spreadsheet or an email to yourself.

Expert tips and common mistakes

Never reuse a password

This is the mistake that causes the most damage. When one site leaks its database, attackers try the same email and password on banks, email and shopping sites. A unique password per account limits a breach to one account.

Don't "improve" a generated password to remember it

Swapping a few letters for something familiar, or tacking on your birth year, cuts the randomness you just paid for. If you can't remember it, that's normal. Store it in a password manager and let the manager remember it.

Don't use predictable patterns

Things like a word plus a year plus an exclamation mark ("Summer2026!") follow patterns attackers try first. Random characters have no pattern to guess.

Match the site's rules, then add length

Some sites cap length or ban certain symbols. Read the rules, untick what's not allowed here, and make up the difference with extra characters. Pasted a password and want to confirm its length? The Word & Character Counter shows an exact count.

Turn on two-factor authentication

A strong password is the first layer. Where a site offers two-factor authentication, use it for email, banking and any account that can reset others.

Treat security answers like passwords

If a site asks security questions, true answers are easy for others to find. Use random text for those answers too, and store them with the password.

Be careful where the password lands

Your clipboard can hold the password until you copy something else. Paste it, then copy a harmless word to overwrite it. Avoid screenshots, chat messages and plain text files. Generate on a device you trust.

Privacy and security

Passwords are generated in your browser and are never uploaded. The generator is plain JavaScript that calls crypto.getRandomValues, which MDN documents as the browser's cryptographically strong random source. The page loads no external scripts, fonts or images, makes no network requests when you generate, and doesn't write passwords to cookies or local storage. Refreshing or closing the tab clears them.

Some risks sit outside this page. Malware or a keylogger on your device can see what you type or copy. Browser extensions can read page contents. A clipboard manager may keep what you copy. The Download .txt button saves an unencrypted file, so delete it after you've stored the passwords properly. Standard hosting logs may record that the page was visited, but they never see the passwords created in your browser.

Troubleshooting

"Choose at least one character type" appears

All four checkboxes are off. Tick at least one type and the password will generate again.

A website rejects my password

The site probably bans certain symbols or sets a maximum length. Untick Symbols, shorten the length to the site's maximum, or both. Then generate again.

Copy doesn't work

Some browsers block clipboard access in certain settings. The tool tries a fallback. If it still fails, click inside the box, press Ctrl+A (Cmd+A on a Mac), and copy with the keyboard.

My length was changed

Lengths below 4 or above 128 are adjusted to the nearest allowed value, and a message tells you so.

The strength says Fair or Weak

Your password is too short or uses too few character types. Raise the length to 16 or more and turn on all four types.

I can't tell O from 0 or l from 1

Tick Easy to read and generate again. The new password avoids I, l, 1, O and 0.

I downloaded a file and want it gone

Delete the .txt file from your downloads folder and empty the trash or recycle bin. Better yet, save passwords in a password manager and skip the file.

I want a password I can say out loud

This tool makes random character strings, not word-based passphrases. Use a shorter length with look-alikes excluded, or a password manager that supports passphrases.

Glossary

Entropy
A measure of unpredictability, counted in bits. More bits means more possible passwords and more guesses for an attacker.
Brute-force attack
Trying many possible passwords until one works. Longer, random passwords make this impractical.
Credential stuffing
Using email and password pairs leaked from one site to try to log in elsewhere. Unique passwords stop it.
CSPRNG
A cryptographically secure pseudo-random number generator, the kind of random source that's safe for security uses.
Password manager
An app that creates, stores and fills in passwords so you only remember one master password.
Two-factor authentication
A second proof of identity, such as a code from an app, required in addition to your password.
Hash
A one-way fingerprint of data. Websites should store hashes of passwords, not the passwords themselves. You can experiment with the Hash Generator.

Frequently asked questions

Is this password generator free?

Yes. It's completely free, with no account, no trial and no limit on how many passwords you generate. There are no ads inside the tool and nothing to install. Open the page, choose your options, click Generate password and copy the result.

Are the passwords really random?

Yes. Each character is chosen with crypto.getRandomValues, the browser's cryptographically secure random source, not Math.random. The code also discards out-of-range values to avoid modulo bias. That makes the output suitable for real accounts, though randomness quality still depends on your browser and device.

Does this site see or store my passwords?

No. Passwords are generated on your device and shown only in the box on this page. The page doesn't send them anywhere or save them in cookies or local storage. Closing or refreshing the tab clears them. Your clipboard or browser may keep copies, so clear them on shared computers.

How long should my password be?

For most accounts, 16 characters with letters, numbers and symbols is a solid default. Use 20 or more for important accounts such as email, banking and your password manager's master password. Longer is stronger, and length matters more than clever symbols. Also check each site's maximum length.

Do I need to include symbols?

Not always. Symbols widen the pool and add strength per character, but extra length does the same job. If a site rejects certain symbols, turn symbols off and raise the length to 20 or more. Letters and numbers alone are fine when the password is long enough.

What does exclude ambiguous characters do?

It removes characters that look alike: capital I, lowercase l, the digit 1, capital O and the digit 0. That helps if you'll type the password from a screen or paper. It shrinks the pool slightly, so add a character or two of length to make up for it.

Is this a replacement for LastPass or another password manager?

No. This tool only generates passwords. It doesn't save, sync or autofill them. Password managers such as LastPass can generate and store passwords for you. A good routine is to create a password here or in your manager, then keep it in a manager instead of reusing it.

Can I use the same generated password on several sites?

You shouldn't. If one site is breached, anyone holding that password can try it on your other accounts. Generate a fresh password for each account and keep them in a password manager. This tool makes that easy: click Generate password again whenever you need another one.

Does it work on my phone and offline?

Yes to both, with one note. The layout is built for phones, with 44-pixel tap targets, and the generator needs no internet connection once the page has loaded. You do need to be online to open it the first time. The tool does not install itself as an offline app.

How strong is my password?

The strength bar shows an estimate in bits of entropy, calculated from the password length and the size of the character set you chose. Eighty bits or more is rated very strong. It estimates randomness only. It can't know whether a website stores passwords safely.
